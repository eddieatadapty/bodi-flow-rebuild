# BODi Growth Audit

**Live → https://eddieatadapty.github.io/bodi-flow-rebuild/**

Five ideas to turn more BODi users into subscribers, each built into a clickable version of BODi's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open on the program the ad sold | +5–10% CR to purchase |
| 02 | Show their program before the price | +10–20% CR to purchase |
| 03 | Name the program on the paywall | +15–20% CR to purchase |
| 04 | Ask for the account after the plan | +5–10% · ARPU +10–17% CR to purchase |
| 05 | Catch the ✕ with three months | ARPU +10–15% from people who close the paywall |

Every price, rating and feature comes from BODi's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for BODi. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
